1. Explain the difference between frontend, backend, and full-stack development.

Answer:
Frontend Development:
Frontend is the part of a website that users can see and interact with. It is built using HTML, CSS, and JavaScript.
Example: The login page of Facebook.

Backend Development:
Backend handles server-side logic, databases, and APIs. It is built using languages like Java, Python, PHP, or Node.js.
Example: Processing a user's login credentials.

Full-Stack Development:
A full-stack developer works on both frontend and backend.
Example: Building a complete e-commerce website from the user interface to the database.

3. Describe how a browser requests and displays a web page from a web server.

Answer:

The user enters a website URL in the browser.
The browser sends an HTTP request to the web server.
The server processes the request.
If required, the server retrieves data from the database.
The server sends an HTTP response containing HTML, CSS, JavaScript, and other files.
The browser downloads these files.
The browser renders the webpage and displays it to the user.

Answer:

Examples:

6. Define the roles of a frontend developer, backend developer, and database administrator in a project.

Answer:

Frontend Developer:
Creates the user interface
Uses HTML, CSS, and JavaScript
Ensures the website is responsive and user-friendly

Backend Developer:
Develops server-side logic
Creates APIs
Connects applications with databases
Ensures security

Database Administrator (DBA):
Designs and manages databases
Maintains backups
Optimizes database performance
Ensures data security
