Responsive CSS Cheat Sheet

Filters

Change how images look.

filter: grayscale(100%);

Media Queries

Apply styles at certain screen widths.

@media (max-width: 700px) { ... }

Responsive Design

Make layouts adapt to different devices.

width: 100%;

Typography

Scale text to fit the screen.

font-size: clamp(1rem, 3vw, 2rem);
