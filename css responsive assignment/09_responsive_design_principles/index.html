Responsive Design Principles

Fluid Layouts

Use flexible sizes so content can grow or shrink with the screen.

width: 100%;

Flexible Media

Images should stay inside their containers instead of overflowing.

img { max-width: 100%; }

Breakpoints

Change the layout when the screen reaches a chosen width.

@media (max-width: 600px)
