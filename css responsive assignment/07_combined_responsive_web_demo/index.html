Responsive Design

Responsive design lets a page adjust to the available space. Flexbox aligns items in a row or column, while Grid creates rows and columns.

Cheat Sheet

Flexbox: display: flex;

Grid: display: grid;

Breakpoint: @media (max-width: 700px)
