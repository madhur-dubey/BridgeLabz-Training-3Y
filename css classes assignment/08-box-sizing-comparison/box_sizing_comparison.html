Box-Sizing Comparison

Compare how CSS calculates the width of a box.

content-box

Width: 250px
Padding: 20px each side
Border: 5px each side

Total width: 300px

border-box

Width: 250px
Padding and border fit inside width

Total width: 250px

With content-box, padding and border are added to the declared width. With border-box, they are included in the declared width.

Try resizing the page to see the boxes stack on small screens.
